## 🚀 How to Deploy on GitHub Pages (Free Hosting)

1. **Create a GitHub Repository:**
   - Go to [github.com/new](https://github.com/new).
   - Name your repository (e.g. `happy-birthday-venu`).
   - Choose **Public**.
   - Click **Create repository**.

2. **Upload / Push the Files:**
   In your project directory terminal, run:
   ```bash
   git init
   git add .
   git commit -m "Happy Birthday Venu celebration website"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```

3. **Enable GitHub Pages:**
   - Go to your repository on GitHub.
   - Click **Settings** (top menu) -> **Pages** (left sidebar).
   - Under **Build and deployment -> Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and folder `/ (root)`.
   - Click **Save**.

4. **Your Live Link:**
   - Within 1–2 minutes, your website will be live at:
     `https://<your-username>.github.io/<your-repo-name>/`
   - Send this link to Venu! 💖
